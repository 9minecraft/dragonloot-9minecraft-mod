# DragonLoot — Forge Endgame Gear From Ender Dragon Scales

DragonLoot 9minecraft Mod rewards players with powerful end-game equipment after defeating the Ender Dragon. It introduces a complete collection of dark purple gear crafted from Dragon Scales, giving you a strong reason to conquer the End dimension. This mod includes armor pieces, versatile tools, ranged weapons, and mount protection designed with a cohesive dragon style.

Drops Dragon Scales when you slay the Ender Dragon to craft top-tier gear.

## What this build is

An unofficial rebuild of **Globox1997**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.

## Source code

This build is released under **GLPv3**. The complete corresponding source ships inside the downloadable file under `META-INF/sources/`, next to the original licence text.
